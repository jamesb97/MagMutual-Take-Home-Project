What did you think of the project?

I think that this project was a good way to test my skills and knowledge of Node.js and Express.js in creating a REST API example with a CSV file. I also enjoyed the challenge of creating a custom endpoint and learning how to use the csvtojson library. 

What didn’t you like about the project?

I didn't like the fact that sometimes when creating endpoints, the data was not always returned as expected. However, it was a great way to learn and understand how to create a REST API example with a sample data file. 

How would you change the project or approach?

I would like to have more time to work on this project and to have more time to learn and understand how to create a REST API example with a sample data file, by challening myself to create more complex endpoints and require more data to be returned, also by utilizing a database query to return the data instead of a sample csv file. What if we wanted to return an endpoint that returns a collection of users based on a specific profession, or returns a specific column not listed in the csv file, or creating a brand new column, then populating it with new records?

Anything else you would like to share?

Thank you for the opportunity to work on this project. I enjoyed the challenge and learned a lot from it. I also enjoyed the opportunity to experience what it is like to build endpoints and gather data from a data file, parse it, and return it in a JSON format. Then use that JSON format to test out a specific set of endpoints. Creating endpoints is an important skill to have as a software developer as it is an essential way to interact with data and perform actions on it.
