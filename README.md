## MAG Mutual Take Home Project

#### Take Home Project

At MagMutual, we're continually evolving our platforms and creating new end-to-end services and experiences for our users. This project represents a smaller, focused example of the type of work we regularly take on.

For this exercise, we’d like you to build a service with endpoints that return the provided data, along with a simple UI to display that data. Feel free to be creative in your solution, we are excited to see what you come up with.

We have provided a CSV containing user information; we would like you to build the following endpoints:

- Endpoint to return a specific user (and all associated information)
- Endpoint to return a list of users created between a date range
- Endpoint to return a list of users based on a specific profession
- Custom Endpoint that you design on your own.

Assumptions:
You can build it in any language/framework combination that you like, or feel is best.

Deliverables:
The artifacts or link to the source code.
Answer the following questions:

- What did you think of the project?
- What didn’t you like about the project?
- How would you change the project or approach?
- Anything else you would like to share?
